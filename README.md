## 项目

### 观澜 WaveAtlas

一个单文件 HTML 音频工具：浏览文件夹内所有音频的波形、点击即播、自动识别 BPM 与情绪。无需安装、无需联网、不上传任何文件。

- 官网 · [waveatlas.top](https://waveatlas.top)
- 在线版 · [直接试用](https://waveatlas.top/app/)
